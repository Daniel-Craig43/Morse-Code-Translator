# Morse-Code-Translator

This project implements a Morse code system that uses a Nuclueo-L452RE programmed using Keil uVision 5. It converts letters (a-z) inputted by the users to its corresponding Morse code by blinking an LED and activating a buzzer. 

Project for:
Microcomputer Systems (ECE 3130)
College of Computer and Electrical Engineering, Tennessee Technological University
Completed by: Harry Rudd, Daniel Craig, Ryan Shipwash, Mashoud Moussa Modi, Daniel Davis
